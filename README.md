## 韩国住宅VPS的“住宅”，到底指什么

IP属性决定它能过哪些风控。住宅IP注册在宽带运营商（韩国就是KT、SK宽带这类）名下，IP库标注为residential或ISP；普通机房IP则被标注为hosting或business。平台做风控时，前者按正常家庭用户处理，后者默认按机器对待。

这里有几个容易混淆的标签，分开说：

- **原生IP**：IP注册在韩国、也从韩国本地播出，归属地和使用地一致。不少商家卖的“韩国VPS”，IP其实是从其他地区广播过去的，IP库里归属地对不上，风控一查就露馅。这是韩国机房的老问题，买之前值得专门确认。
- **双ISP**：IP在主流IP数据库里都被识别为ISP类型（宽带），而不是hosting。只在一个数据库里认、另一个不认的，用到特定平台就会翻车。
- **住宅属性**：以上两条都满足，才称得上真正的住宅IP。
